# 🎣 Albion Online — Fishing QTE Assistant (Автоматическое удержание поплавка)

Программа для автоматического прохождения мини-игры рыбалки (QTE) в **Albion Online**.  
Она непрерывно анализирует область экрана с помощью компьютерного зрения (OpenCV + MSS), мгновенно определяет появление мини-игры рыбалки и удерживает поплавок в безопасной зелёной зоне, своевременно зажимая и отпуская левую кнопку мыши (ЛКМ).

---

## ⚡ Особенности

- **Высокая скорость работы**: Захват экрана и анализ работают со скоростью **~80-100 FPS** с микросекундными задержками и минимальной нагрузкой на процессор.
- **Двойной алгоритм распознавания**:
  1. Определение нижней синей шкалы прогресса как якорного ориентира.
  2. Точный трекинг поплавка по характерному белому шарику, верхнему оранжевому оперению и шаблону.
- **Два режима механики (Стандарт / Инверсия)**:
  - **Стандарт Albion Online**: Удержание ЛКМ тянет поплавок вправо (подсечка/натяжение), а отпускание ЛКМ возвращает его влево.
  - **Инвертированный режим**: Удержание ЛКМ смещает поплавок влево, отпускание — вправо (переключается клавишей **F7** или в окне программы).
- **Интерактивный графический интерфейс (Dark Theme)**:
  - Живая шкала натяжения (Live Gauge) с отображением границ зон и текущего положения поплавка в реальном времени.
  - Индикатор состояния мыши (Зажата / Отпущена).
  - Счётчик выловленной рыбы.
- **Глобальные горячие клавиши** (работают прямо во время игры):
  - **`F5`** — Старт / Пауза
  - **`F7`** — Переключение режима управления (Стандарт ⇄ Инверсия)
  - **`F8`** — Тестовый снимок (проверка распознавания полосы и поплавка)
  - **`F10`** или **`Esc`** — Экстренная остановка и гарантированное отпускание мыши
- **Защита от античита (Humanization)**:
  - Рандомизация микро-задержек между нажатиями (человеческий фактор).
  - Использование аппаратных событий Windows API (`mouse_event`).

## 🚀 Быстрый запуск

1. Установите зависимости (если запускаете на новом компьютере):
   - Дважды кликните по **`install.bat`** (или выполните команду `pip install -r requirements.txt`).
2. Запустите программу:
   - **`start_fast_bot.bat`** — быстрый легковесный бот в консоли с ASCII-шкалой (Color Masking + Гистерезис).
   - **`start.bat`** — полноценный графический интерфейс (GUI) с живой шкалой и настройками.
3. В игре **Albion Online** подойдите к водоёму и забросьте удочку.
4. Нажмите **`F5`** для активации бота.
5. Когда рыба клюнет — нажмите ЛКМ для подсечки.
6. Бот автоматически перехватит управление и удержит поплавок в зелёной зоне до поимки рыбы!

## ⚙️ Настройка порогов (Sliders)

- **Нижний порог (Min %)** — по умолчанию `42%`:
  - Когда поплавок опускается ниже этого значения, ЛКМ зажимается, чтобы подтянуть рыбу.
- **Верхний порог (Max %)** — по умолчанию `76%`:
  - Когда поплавок приближается к правой опасной (красной) зоне, ЛКМ отпускается, чтобы не порвать леску.

## 📁 Структура проекта

- `app.py` — главное приложение с графическим интерфейсом Tkinter и монитором горячих клавиш.
- `detector.py` — модуль компьютерного зрения для распознавания шкал и поплавка.
- `controller.py` — контроллер мыши с гистерезисом и рандомизацией задержек.
- `capture.py` — высокоскоростной захват экрана (MSS + Windows Desktop API).
- `test_detector.py` — тестовая утилита для проверки распознавания на скриншотах.
- `config.json` — сохранённые настройки программы.
- `start.bat` — скрипт быстрого запуска.
